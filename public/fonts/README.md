# Self-hosted Fonts

Place the following files in this directory after downloading them from Google Fonts:

- `ubuntu-latin-400.woff2`
- `ubuntu-latin-500.woff2`

Optional monospaced accent:

- `ubuntu-mono-latin-400.woff2`

Keep filenames lowercase and hyphenated to match the `@font-face` declarations in `src/styles/global.css`.
